# 02 — Methods at a Glance

Pipeline: source PDF -> hierarchy/table extraction -> district/scenario evidence -> manual visual
recovery of 4 undetected table families (HEIGHT, BUILDING SITING, PARKING, ALLOWED USES) -> review/
overrides -> frozen score-input release -> V1.0 scoring (predeclared policy-band rubrics, 0-100,
5-domain weighted formula) -> 6 required sensitivity variants -> independent final validation.
See docs/METHODOLOGY.md and docs/SCORING_PROTOCOL_V1.md for full detail.

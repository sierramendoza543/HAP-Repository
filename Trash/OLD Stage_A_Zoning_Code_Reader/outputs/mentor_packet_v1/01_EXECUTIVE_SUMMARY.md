# 01 — Executive Summary

A source-linked pipeline collected, verified, and scored residential zoning rules for Bridgeport, CT
(24 districts, form-based code) and Greenwich, CT (RA-4 prototype district), across nine of twelve
predeclared comparability variables (lot size, lot width, placement, parking, 3+-unit entitlement,
ADU entitlement, density/unit cap, missing-middle entitlement, discretionary-review burden).

Headline, stable across six required sensitivity variants: Greenwich RA-4 scores 76.5/100;
Bridgeport's 28 score-eligible building-form scenarios range 19.1-56.7
(median 27.4). All 28 fall below the Greenwich benchmark.

# 00 — Read Me First

This packet summarizes the **Scenario-Aware Comparative Residential Regulation Index, Version 1.0 (Source-Linked Pilot)** —
a source-linked comparison of Greenwich RA-4 and Bridgeport's scored residential building-form scenarios.

> This is a pilot. It does not rank Bridgeport vs. Greenwich as towns, does not claim either town is
> universally more or less restrictive, and makes no causal claim about housing production.

Read order: 01 Executive Summary -> 02 Methods -> 03 Key Results -> 04 Score Interpretation ->
05 Limitations -> 06 Adversarial Review Summary -> 07 Artifact Index.
